## 严重缺陷与复核

### 规范审查（Standards）

独立只读审查发现的事件预算阻止启动恢复、跨服务同目录互斥不足、SSE 重连游标优先级错误均已修复。运行终止事件保留写入空间；使用 proper-lockfile 提供跨进程工作目录租约；Last-Event-ID 优先于旧 query 游标。20 项回归包含真实磁盘 10000 事件恢复、两个服务竞争同目录及实际 SSE 响应序列。

### 规格审查（Spec）

独立只读审查确认超长 JSON 在解析前截断会吞掉失败：现先解析完整协议，再限制展示字符串。40000 字符终态错误由真实 Node 子进程回归验证。运行检查器增加 run.id 和 effect 销毁保护，避免旧请求或 SSE 回写新选择。

后续复核还修复原始日志目录初始化失败后可能遗留已启动子进程的问题：所有日志目标先于 spawn 创建；故障注入证明不再出现子进程文件副作用。日志摘要改为增量哈希，避免整份大日志重新读入内存。最终只读复核没有发现新的可复现 P1；这不构成对所有路径无缺陷的保证。
