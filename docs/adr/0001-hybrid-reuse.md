# 采用混合复用架构

首版面向用户自己的本地开发场景，需要用 TypeScript、React 与 React Flow 组装可视化工作流，同时保持“极小循环，其他一切皆节点，智能是可选的”。用户已选择混合复用路线：采用成熟画布、模型 SDK、Schema、工具执行和验证组件，自研工作流的节点契约、状态传递、边路由、循环控制、组合卡片和运行追踪。相比更多自研集成代码或整体扩展现成框架，这条路线既保留产品所需的图语义，又减少对成熟能力的重复实现。

## 决策范围

本决策确认总体架构路线，具体组件与版本根据[推荐技术组合](../research/recommended-stack.md)和后续需求选定。恢复级别、并发语义、插件权限及首批验收场景仍待访谈；若这些需求超出小内核的合理范围，可在保持混合复用原则下组合成熟的图执行能力，并记录后续决策。

需求进展以[访谈记录](../requirements/interview.md)为准。当前继续需求访谈，尚未进入产品实现。
