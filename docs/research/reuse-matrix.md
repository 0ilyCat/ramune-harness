# 复用矩阵：候选、证据、入口与选择

完成日期：2026-10-09（Asia/Shanghai）；源码和发布信息采集于 2026-10-08。**Adopt**：直接依赖成熟组件；**Extend**：在其公开扩展点或经审计 fork 上增加产品功能；**Compose**：以 adapter/节点组合已有能力；**Build**：仅实现已有组件未提供的 Ramune 产品语义。参考设计不等于已经复用源代码。

维护判断来自提交、实际版本发布时间、官方 EOL 公告；不采用 Stars。HEAD/源码 package version 与 npm stable 分开记录；本轮未安装/运行候选，没有性能或安装兼容实测。许可列针对核查的代码范围，第三方依赖及发行产品另按 notices 判断。

## 5. 有理由自研的范围

这些是 Ramune 的产品模块，不是要重造上游库的候选：

| Build 项 | 为什么已有组件不能直接代替 | 必须复用的底座 |
| --- | --- | --- |
| Workflow document / compiler | React Flow 保存的是 UI graph；本项目要有 node type/version、port/schema、binding、enabled、循环/组合与迁移 | JSON、Zod；需要任意 schema 时 Ajv；React Flow 仅作布局 adapter |
| Node Registry / adapter contract | 运行 executor、描述元数据和 renderer 需一致；不能把 UI nodeTypes 当 executable plugin registry | SDK/工具公开接口，明确 trusted static plugins 与动态 code 的不同 |
| 有界 Kernel | 用户图的路由/状态/循环语义是核心产品；默认无 LLM、纯规则图可运行 | 不写 Provider/进程/DB/测试器。若恢复/并发复杂则 Extend LangGraph |
| Port/binding 与 disabled/composite 规则 | 跳过、identity bypass、缓存/替换及组合映射并非一回事 | 已有 validators/路径规则；不编造全 JSON Schema assignability 算法或 eval 引擎 |
| Trace correlation / Inspector | 不同节点工具的事件需要以 run/invocation/attempt/iteration/parent 关联，观察输入输出/日志/时间/错误 | SDK 流、工具原生报告、SSE 与 React Flow UI primitives |
| 权限与 Secret reference | 库不能替应用知道用户批准了哪个 workspace、命令、图版本与网络能力 | OS/容器隔离、后端 secret、成熟 credential store（若后续需要）；不自制加密方案 |
| 模板 Graphs | Chat/Coding/Ralph/自主开发应是可修改图，不是 Kernel 特判 | Model/Tool/Context/Check/Router/Composite 通用节点 |

不推荐并列采用 Pi、DeepSeek、LangGraph、AI SDK 高层 Agent，使同一层循环和工具权限出现多个 owner。底座的具体版本锁定、依赖许可总审计和集成测试属于下一阶段；本轮没有承诺这些组件已经在同一应用中兼容运行。
